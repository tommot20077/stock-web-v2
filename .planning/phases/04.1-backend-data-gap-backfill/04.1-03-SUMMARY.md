# Phase 04.1 Plan 03: AssetFacade.findProfiles 與 FxRateFacade 三角換算 Summary

**trading 之後可經 `AssetFacade#findProfiles` 一次批次取得資產的幣別 / 類型 / 產業（不 JOIN assets），並經 `FxRateFacade#currentRates()` 取得以固定順序「同幣 → 直接列 → 反向列 → 經 USD → empty」換算的 `FxRates`。**

## Accomplishments

- Task 1（tracer）：`AssetProfile` -> `AssetFacade#findProfiles` -> `AssetFacadeImpl`（單一具名參數 `IN` 查詢，空集合不查 DB，查無者省略）-> 三條 IT；`MockDataProviderContractTest.FakeAssetFacade` 與 `BacktestServiceTest.InMemoryAssetFacade` 補上方法。
- Task 2：`FxRate` / `FxRates` 純值物件，9 條單元測試以 V2 seed 數值釘死（`TWD→USD = 0.030847` 取直接列而非 `1/32.418`、`EUR→TWD = 35.1151776`、`2000 USD → 64836.00000000`）。
- Task 3：`FxRateFacade`（infrastructure）+ `FxRateFacadeImpl`（asset）讀 `fx_rates`，壞幣別 / 非正匯率列 WARN 後略過（只記列 id）。
