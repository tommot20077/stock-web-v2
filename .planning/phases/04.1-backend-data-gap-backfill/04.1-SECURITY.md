## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| browser cookie -> PATCH /me/preferences, POST /portfolio/cash-entries | cross-site request riding cookie auth | base currency, cash amounts |
| request body / Idempotency-Key -> cash_ledger_entries | user-controlled strings into append-only ledger | amount, note, key |
| exception -> error envelope | which strings leave the server | Jackson / validation messages |
| trading module -> users/assets/fx (Facade) | cross-module reads | base currency, asset profile, fx rates |
| Redis summary/holding cache | per-user derived valuation | portfolio values |
| FE -> apiClient -> BE | sole transport boundary | CSRF header, cookies, envelope |
