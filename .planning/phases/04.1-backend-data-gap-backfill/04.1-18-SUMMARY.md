## View-model 形狀

```ts
interface KpiCard {
  l: string;                       // 小標
  v: string;                       // Display 數值(不含幣別代碼)
  ccy?: string;                    // 獨立 .kpi-ccy span;數值缺值(—)時不帶
  s?: string; sTestid?: string;    // 副標 / 比率列
  arrow?: '↗' | '↘'; tone: 'up'|'dn'|'dim';
  notes?: { testid: string; text: string }[];  // 常駐說明 Hint 列
  isCash?: boolean;                // 可用現金卡:附加餘額 / 提示 / 動作列
}
interface AllocRow { key; label; color; value; amount: string | null; weightText: string }
```

- 今日損益:`dayPricePnl == null` → 數值 `—`、不帶代碼、無比率列;`0` → `0 TWD` 無號無箭頭;`dayPnlExcludedCount > 0` 才有 `overview-kpi-day-pnl-excluded`;`overview-kpi-day-pnl-note` 常駐。
- 分類色與標籤(`ALLOCATION_CATEGORIES`):STOCK `var(--accent)`、CRYPTO `#3b82f6`、FX `#a855f7`、BOND `#f59e0b`、CASH `#94a3b8`;未知 enum → `assetTypeOther` + `var(--fg-dim)`。swatch 帶 `data-color`(jsdom 會把 hex 正規化成 rgb,斷言顏色字面需要此屬性)。

## 基準幣切換狀態機

```
idle ──click(非選中)──▶ switching(PATCH in flight:四鍵 disabled、base-currency-switching role=status)
  ▲                          │ 成功:savedCurrency = 回應值;bumpPortfolioRevision('baseCurrency')
  │                          ▼
  └──── refreshSummary finally ◀── reloading(summary 重讀中:四鍵仍 disabled,由「更新中…」承擔播報)
        失敗(switching):pending 清除、回原值、base-currency-error role=alert(無重試鈕)→ idle
```

- 選中值 = `pendingCurrency ?? savedCurrency ?? summary.baseCurrency`;任何一次 summary 重讀成功就清 `savedCurrency`(以後端為真值);重讀失敗時 `savedCurrency` 保留,金額仍帶舊代碼並顯示 `portfolioStaleAfterBaseCurrency`(每個金額自帶代碼,不會有「標示 USD、實為 TWD」)。
- 錯誤分派複製自 Settings(`VALIDATION_FAILED` + `fields.baseCurrency` / CSRF / 403 / 網路 / 其他);401 不顯示(交給全域 SessionBanner);後端 `message` 與 `fields` 的 value 不入 DOM(測試以 canary 守門)。
- 點已選中者:不發請求、不進狀態機。
