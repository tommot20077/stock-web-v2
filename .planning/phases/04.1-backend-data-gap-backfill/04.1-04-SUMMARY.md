# Phase 04.1 Plan 04: 現金分錄帳本 V15 與冪等入出金端點 Summary

## 凍結契約（04.1-10 / 04.1-12 / 04.1-15 / 04.1-22 依此，字面照 plan <interfaces>）

- `POST /api/v1/portfolio/cash-entries`，header `Idempotency-Key`（必填，1–128，不得全空白），權限 `TRADE_EXECUTE`，成功 200 `ApiResponse<CashEntryDto>`。
- body `CreateCashEntryRequest`：`type` String（`DEPOSIT` / `WITHDRAWAL`，大小寫不敏感）、`currency` String（`USD` / `TWD` / `EUR` / `JPY`）、`amount` number（`0.00000001` ≤ x ≤ `1000000000000`，整數最多 13 位、小數最多 8 位）、`note` String（≤ 500，選填）、`occurredAt` ISO-8601（選填；省略 = 伺服器現在；不得晚於現在 5 分鐘以上）。
- 回應 `CashEntryDto`：`id`（UUID 字串）、`type`、`currency`、`amount`（JSON number）、`note`、`occurredAt`、`createdAt`、`reversalOfId`（UUID 字串或 null）、`reversalOfOccurredAt`（或 null）、`reversed`（boolean）。本 plan 建立的分錄 `reversalOfId = null`、`reversed = false`；不含 `idempotencyKey`。
- 錯誤：400 `VALIDATION_FAILED`（`fields` 鍵：`type` / `currency` / `amount` / `note` / `occurredAt` / `Idempotency-Key`）、409 `CASH_IDEMPOTENCY_KEY_REUSED`、403、429。
- 冪等比對維度：`type`、`currency`、`amount`（compareTo）、`occurredAt`（僅在請求有送時比對，`isEqual`，截到微秒）；**不含 `note`**。

**本 plan 實際已實作 vs 留給 04.1-22**：已實作 header 綁定、key 空白 / 超長驗證（`fields['Idempotency-Key']`）、`type` / `currency` 白名單（`fields.type` / `fields.currency`）、bean validation 的 `amount` / `note` 規則（由 `GlobalExceptionHandler` 轉成 `fields`）。**未實作**（04.1-22）：`CASH_IDEMPOTENCY_KEY_REUSED` 與 payload 比對（冪等命中目前直接回既有分錄）、`occurredAt` 未來時間檢查、稽核事件 `cash_entry_create`、對應 WebMvc / IT 擴充。
