## 凍結契約（前端 04.1-12 / 04.1-13、後端 04.1-21 依此）

- `GET /api/v1/me` -> `data.baseCurrency`：`"TWD" | "USD" | "EUR" | "JPY"`（enum 常數名字串）。同一 `MeResponse` 也內嵌於 login / register / refresh 回應。
- `PATCH /api/v1/me/preferences`，body `{"baseCurrency":"USD"}` -> 200 `ApiResponse<MeResponse>`。
  - 缺 / 空白（`@NotBlank` 或 service 判定）-> 400 `VALIDATION_FAILED`，`error.fields.baseCurrency = "must not be blank"`
  - 不支援的幣別 -> 400 `VALIDATION_FAILED`，`error.fields.baseCurrency = "unsupported currency"`（靜態，不回射輸入）
  - 超過 10 字元 -> 400 `VALIDATION_FAILED`（`@Size(max = 10)`，Bean Validation 的 fields 訊息）
  - 格式錯誤 JSON -> 400 `VALIDATION_FAILED`（04.1-01 的 D-27 handler，無 fields）
  - cookie 認證缺 `X-XSRF-TOKEN` -> 403 `AUTH_CSRF_TOKEN_INVALID`；bearer 不需 CSRF；未認證 -> 401
  - 稽核事件：`preferences_update`（`success` / `failure:<ERROR_CODE>`）
  - 不要求 `Idempotency-Key`（設定值天然冪等）
