# Phase 04.1 Plan 24: CashBalanceCalculator Summary

**把 `List<CashFlow>` 依幣別加總成 `EnumMap` 餘額的無 I/O 純函式,負值照實保留、scale 8 HALF_UP,供 04.1-09 接線與 04.2 現金股利擴充。**

## 最終簽章(04.1-09 依賴)

```java
public record CashFlow(CurrencyCode currency, BigDecimal amount) {}   // 正 = 流入、負 = 流出

public final class CashBalanceCalculator {
    public static Map<CurrencyCode, BigDecimal> balances(List<CashFlow> flows);
}
```

- 回傳 `EnumMap<CurrencyCode, BigDecimal>`:迭代順序依 `CurrencyCode` 宣告順序(USD、TWD、EUR、JPY)。
- 只含出現過的幣別;同幣別正負抵銷為 0 時仍保留該鍵(值為 `0E-8`,比較請用 `compareTo`);空輸入回空 map。
- 每個幣別先以 `BigDecimal::add` 完整加總,最後才 `setScale(8, HALF_UP)`;負值不夾 0(D-08)。
- 不持久化任何餘額(D-10)。呼叫端(04.1-09)負責把入出金淨額與交易現金流組成 `List<CashFlow>`。
- 計算器不做 null 檢查:`flows` 或元素為 null 會 NPE,呼叫端不得傳 null(04.1-09 由 SQL 聚合結果組裝,不會有 null)。
