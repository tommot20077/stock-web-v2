## TradeDto 最終欄位（供 04.1-10 寫契約檔）

```java
public record TradeDto(
    String id,                  // 交易 UUID
    String symbol,
    String type,                // BUY | SELL
    BigDecimal quantity,
    BigDecimal price,           // 標的交易幣別
    BigDecimal fee,             // 標的交易幣別
    String note,                // nullable
    OffsetDateTime executedAt,
    OffsetDateTime createdAt,
    String currency             // 新增：CurrencyCode 常數名（USD/TWD/EUR/JPY）；理論上必有，profile 缺失時為 null
)
```
