## Sampling Rate

- **After every task commit:** 對應層 quick run(後端該模組 `-Dtest=...`;前端該檔 `npx vitest run <file>`)
- **After every plan wave:** 後端本機 full + arch gate + `spotless:check`;前端 full(含 `VITE_DATA_MODE=api` 與 lint)
- **Before `/gsd-verify-work`:** 上述全綠 **且 CI Integration job 綠**(IT 只能在 CI 證明,judgment §8);跨 repo 兩邊驗證
- **Max feedback latency:** 120 seconds(單一 quick run)
