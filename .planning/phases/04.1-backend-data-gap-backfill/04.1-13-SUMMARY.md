## 狀態機(Settings.vue)

`loading | loadError | idle | saving | saved | saveError`

| 狀態 | select | 狀態列 / 錯誤區 | 播報 |
|------|--------|-----------------|------|
| loading | disabled | `載入中…` | status |
| loadError | disabled | `loadFailed` + code + traceId(有才渲染)+ `authRetry` 鈕(36px) | alert |
| idle | 可選,值 = 已儲存值 | 空 | — |
| saving | disabled,顯示新值 | `儲存中…` | status |
| saved | 新值 | `已儲存`(保留到下次變更,無計時器) | status |
| saveError | 回到已儲存值 | `--dn` 錯誤文案 + code + traceId,**無重試鈕**(再選一次即重試,PATCH 冪等) | alert |

選回已儲存的值不送 PATCH。未設定時後端預設 TWD,讀取完成前以 TWD 顯示並 disabled。

## 儲存錯誤分派表

| 條件 | i18n key |
|------|----------|
| 非 `ApiClientError`(fetch reject) | `baseCurrencyErrNetwork` |
| status 401 | 不顯示(交給全域 SessionBanner),select 回到已儲存值 |
| `VALIDATION_FAILED` 且 `fields.baseCurrency` 存在 | `baseCurrencyErrUnsupported` |
| `AUTH_CSRF_TOKEN_INVALID` / `AUTH_CSRF_TOKEN_MISSING` | `baseCurrencyErrCsrf` |
| 其他 403 | `baseCurrencyErrForbidden` |
| 其餘(含沒有 `fields.baseCurrency` 的 400、500) | `baseCurrencyErrUnknown` |

只把 i18n key、`error.code`、`requestId`(traceId)存進 state;`error.message` 與 `fields` 的 value 從不進入元件 state,測試以 `BACKEND-MESSAGE-CANARY` 與 `unsupported currency` 斷言不在 DOM。
