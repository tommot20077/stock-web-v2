## Spacing Scale

沿用 `04-UI-SPEC.md` 的**值鍵 token**(`s-12` 永遠是 12px),不使用 t-shirt 名稱(避免與 `02-UI-SPEC.md` 同名不同值,見 Phase 4 U-17)。

| Token | Value | Usage(本 phase) |
|-------|-------|------------------|
| `s-4` | 4px | KPI 小標與數值間、數值與幣別代碼間(`margin-left`)、診斷列 gap、`.ccy-seg` 內襯與按鈕 gap |
| `s-8` | 8px | 控件垂直內距、KPI 動作鈕 gap、欄位錯誤與輸入框間距、legend 列垂直內距、幣別標籤水平內距 |
| `s-12` | 12px | 控件水平內距、KPI 動作列上方間距、兩欄輸入 gap、表格儲存格水平間距 |
| `s-16` | 16px | KPI 卡垂直內距、卡片標題下方間距、`.sectors` 列距、對話框 header / footer 垂直內距 |
| `s-20` | 20px | **僅限**既有卡片水平內距 `padding: 20px`(Overview / Positions 卡片現值,本 phase 延用不改) |
| `s-24` | 24px | 對話框 body 內距、header / footer 水平內距、`.sectors` 欄距 |
| `s-32` | 32px | 對話框 result 步驟水平內距 |
| `s-48` | 48px | 對話框 result 步驟上方留白;**禁止**用於表單區 |

**Exceptions(本 phase 重建範圍內唯一允許不是 scale 值的 6 類):**

1. `1px` 邊框與陰影偏移。
2. 圖形尺寸(非版面間距):`Donut` 的 `size` / `thickness`、legend 色塊 `8px`、產業 bar 高 `6px`(`Positions.vue` `.sec-bar`)、權重 bar `60px × 4px`(`.bar`)。
3. 控件尺寸下限:input / 次要按鈕 `min-height: 36px`;`.inp.big` 與主要 CTA `min-height: 44px`;`✕` 觸控目標 `44px`。
4. 圓角 `4px / 8px / 10px / 12px / 14px / 99px` 屬 radius,不受 spacing scale 約束。
5. inline pill(`.ccy-tag`、`.fresh-badge`、`.status-pill`)的 `padding: 0 8px` + `line-height: 1.2` —— 為了不改列高(沿用 `Positions.vue` `.fresh-badge` 註解的算法)。
6. **既有、本 phase 不碰的頁面骨架**:`.page { padding: 22px }`(`Overview.vue:428`、`Positions.vue` `.page`、`Settings.vue:286`)、`.grid gap: 16px`、Phase 3 已驗收的 `.block-error .details gap: 4px 10px`。這些不是本 phase 新寫的,不遷移(與 `04-UI-SPEC.md` 「Positions / Trades / Overview 的既有版面不在遷移範圍」同一原則)。

- `letter-spacing` 一律 `0`(`.kpi-v` 現值 `-0.5px` 取消)。

## Money & Number Formatting Contract

RESEARCH Q1.5 指出前端金額一律寫死 `$`(`Overview.vue:395`、`Positions.vue:9,650` 等),D-05 之後那些數字是基準幣(預設 TWD)。本節取代 API mode 下所有 `'$' +` 寫法。

**新 helper `src/moneyFormat.ts`(純函式,附 `moneyFormat.test.ts`):**

| 函式 | 輸出 | 例 |
|------|------|----|
| `fmtMoney(value: number \| null, code: string, dp: number)` | `fmtNum(value, dp)` + `U+00A0` + `code`;`null` / 非有限值 → `—`(**不帶代碼**) | `1,234,567 TWD` |
| `fmtSignedMoney(value, code, dp)` | `> 0` 前綴 `+`、`< 0` 前綴 `-`、`= 0` **無號** | `+12,481 TWD` / `-3,200 TWD` / `0 TWD` |
| `minorUnits(code)` | `JPY` → `0`,其餘 → `2` | — |
| `fmtRatioPct(ratio: number \| null)` | `ratio × 100`,2 位小數、帶號;`null` → 不渲染該行 | `+1.04%` |
| `fmtWeightPct(weight: number \| null)` | `weight × 100`,1 位小數、無號;`null` → `—` | `52.0%` |

**選擇代碼後綴而非幣別符號(U-01):** `Intl` 的 `currency` 樣式會讓 USD 與 TWD 都可能顯示為 `$` 系列、JPY 與 CNY 共用 `¥`;本系統同時顯示原幣與基準幣,符號歧義正是這次要修的錯誤本身。ISO 代碼後綴在 zh / en 兩語言一致,且右對齊時數字仍對齊。

| 值 | 格式 | dp |
|----|------|----|
| 基準幣總額(KPI、Positions 彙總卡、標題列、legend、產業金額) | `fmtMoney(v, summary.baseCurrency, 0)` | 0 |
| 基準幣帶號總額(今日損益、總損益、產業未實現損益) | `fmtSignedMoney(v, base, 0)` | 0 |
| 各幣別現金餘額 | `fmtSignedMoney(v, code, minorUnits(code))`,正數不帶 `+`(只有負號) | 依幣別 |
| 入出金金額 | 入金 `+`、出金 `-` + `fmtNum(v, minorUnits(code))` + 代碼 | 依幣別 |
| 持倉列(原幣) | **裸數字**(不帶 `$`、不帶代碼),幣別以該列的 `.ccy-tag` 表示一次(U-01);dp 沿用現值(均價 / 現價 2、市值 / 損益 0) | 現值 |
| 比率 | `fmtRatioPct` | 2 |
| 權重 | `fmtWeightPct` | 1 |

**KPI 與彙總卡的代碼呈現:** 數值與代碼拆成兩個 span —— `<span class="num">1,234,567</span><span class="kpi-ccy">TWD</span>`,代碼為 Label 12px/600 `--fg-dim`、`margin-left: 4px`,避免與 Display 數值爭焦點。

**前端不換匯(D-21):** 所有基準幣數字都直接取後端欄位;前端唯一的算術是 `× 100` 的百分比格式化,以及出金時「金額是否大於該幣別餘額」的比較(只決定是否顯示提示,不顯示計算結果)。

## Accessibility Contract

- **對話框:** `role="dialog" aria-modal="true" aria-labelledby`;開啟時焦點進入(form → 金額輸入;reversal → 備註);關閉時焦點回到開啟者(§3)。`Esc` 關閉(送出中除外)。**焦點圈套(focus trap):** 與 OrderTicket 一致,本 phase 不做(OrderTicket 亦無;記為兩者共同的 a11y 缺口,U-23)。
