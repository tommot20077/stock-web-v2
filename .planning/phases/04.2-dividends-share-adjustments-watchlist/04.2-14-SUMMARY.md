# Phase 04.2 Plan 14：即時報價 WS client 服務層 Summary

前端新增第一個 WebSocket client：`createQuoteStream`。API mode 下，ticket 經 `apiRequest` 取得（帶 CSRF），每個分頁只開一條參考計數的連線。`useLiveQuotes` 把 tick 疊到 GET 報價上，並算出每列的 `ws / rest / none` 資料來源；mock mode 是明確的假推播。另加守門測試，確保 pages / components 不直接使用 WebSocket。

## 做了什麼

- **Task 1（tracer）**：`quoteStream.ts` 跑通主路徑：watch → `POST /api/v1/market/ws/ticket`（經 `apiRequest`）→ 用回應的 `wsUrl` 組同源 `ws(s)://{host}{wsUrl}?ticket=…` → `WELCOME` 後轉 `live`，送出一則完整 `SUBSCRIBE` → `TICK` 的字串價格只在 `parseTickData` 一處轉成數字，每 250 ms 用新 Map 換掉 `ticks`。另外新增 `FakeWebSocket` 替身，並把 `pageApiClients.quotes` 掛上。
- **Task 2**：完成狀態機（見下）、`visibilitychange` 監聽、5 s 釋放延遲、200 ms 訂閱合併、送出節流（PONG 走優先佇列）、channel 自檢、`dispose` 清掉所有 timer / listener / socket；`createMockQuoteStream` 每秒對被 watch 的 SYMBOLS / CRYPTO 代號做 ±0.5% 隨機漫步。
- **Task 3**：`useLiveQuotes` 以純 computed 疊加（不寫回原 rows），提供 `quoteSource` / `isLive` / `lastUpdatedAt`；`wsBoundary.test.ts` 用 `import.meta.glob('?raw')` 逐檔掃描。

## QuoteStream 介面字面（04.2-23 / 04.2-24 依此）

```ts
export type QuoteStreamStatus = 'idle' | 'connecting' | 'live' | 'degraded' | 'replaced' | 'closed';
export interface LiveTick { symbol: string; price: number; time: string; receivedAt: number }
export interface WsTicketResponse { ticket: string; expiresIn: number; wsUrl: string }
export interface QuoteStream {
  mode: RuntimeDataMode;
  status: Readonly<Ref<QuoteStreamStatus>>;
  ticks: Readonly<Ref<ReadonlyMap<string, LiveTick>>>;
  lastDataAt: Readonly<Ref<number | null>>;
  resyncSeq: Readonly<Ref<number>>;
  watch(symbols: readonly string[]): () => void;
  reconnect(): void;
  dispose(): void;
}
createQuoteStream(mode, deps?: { basePath?; socketFactory?; issueTicket?; now?; document?; random?; location? })
useLiveQuotes(rows: Ref<readonly AssetDto[]>, stream: QuoteStream, options?: { restFetchedAt: Ref<number | null> })
  → { rows: ComputedRef<LiveQuoteRow[]>, quoteSource(symbol), isLive(symbol), lastUpdatedAt: ComputedRef<number | null> }
```

## 狀態機的邊（實作）

| 從 | 事件 | 到 |
|----|------|----|
| idle | watch（≥ 1 個合規代號）且前景 | connecting |
| connecting | WELCOME | live（退避歸零、4001 額度重設、resyncSeq + 1、送一則完整 SUBSCRIBE） |
| connecting | ticket 失敗（非 401）/ socket 建立失敗 / wsUrl 非同源 | degraded → 退避 → connecting |
| connecting | ticket 401 | closed |
| live / connecting | close 4000 / 4003（有消費者）/ 4008 / 4009 / 4400 / 4500 / 1006 | degraded → 退避 1/2/4/8/16/30/30 s → connecting（每次重取 ticket）；4008 / 4400 會 console.warn（只帶關閉碼） |
| live / connecting | close 4001（本輪第一次） | connecting（立即重取 ticket） |
| live / connecting | close 4001（第二次） | closed |
| 任何 | close 4002 或 `auth_expired` reason=`session_replaced` | replaced（client 主動 close(1000)，不自動重連） |
| replaced / closed | reconnect() | connecting（有消費者）或 idle |
| 任何 | close 時沒有消費者（含 4003） | idle |
| 任何 | visibility hidden | close(1000) → idle（replaced / closed 維持不變；訂閱集合保留） |
| idle | visibility visible 且有消費者 | connecting |
| 任何 | 最後一個消費者釋放後 5 s | close(1000) → idle（replaced / closed 維持不變） |

## 四個 RESEARCH [ASSUMED] 值的落地方式

1. **5 s 釋放延遲**：`RELEASE_DELAY_MS = 5000`；5 s 內再有人 watch 會取消關閉（有測試）。
2. **5 分鐘 GET 重讀由頁面負責**：service 不排程 GET，只在每次 WELCOME 時遞增 `resyncSeq`。頁面（04.2-23 / 04.2-24）要 watch `resyncSeq` 重讀，另自行加上每 5 分鐘的 timer；rows 一替換，`useLiveQuotes` 就以當下的 ticks 快照為新基準。
3. **保留 maxSubscriptions**：client 不讀 WELCOME 的任何上限欄位（`maxSubscriptions` / `maxTickSubscriptions` 都不讀），不依賴 04.2-01 是否已合入；超過上限時以 `SUB_ACK.rejected` 處理，被拒的 channel 在同一條連線上不重送。
4. **「更新於」用前端收到時間**：`LiveTick.receivedAt = now()`（收到 TICK 時），`lastUpdatedAt = max(restFetchedAt, 範圍內新 tick 的 receivedAt)`；不擴充 `AssetDto.priceTime`。

**1. [Rule 3 - Blocking] RED commit 附帶型別骨架**

- **Commit:** 9b833fd、74ca21c

**2. [Rule 2 - Missing critical] wsUrl 同源檢查與 socket 建構例外吞掉**
- **Found during:** Task 1
- **Issue:** 計畫只說「以回應的 wsUrl 組同源 URL」。如果直接串接，絕對 URL 會讓 client 連到別的主機；瀏覽器的 `new WebSocket` 建構例外訊息也會含完整 URL（也就是含 ticket）。
- **Fix:** wsUrl 必須以 `/` 開頭且不是 `//`，否則當連線失敗並退避；建構例外吞掉，不轉拋、不記錄（console spy 測試涵蓋）。
- **Files modified:** quoteStream.ts
- **Commit:** c6303e5、aa9b72f

**3. [Additive] QuoteStreamDeps 新增 `location?`**
- **Found during:** Task 1（Test 1b）
- **Issue:** jsdom 的 `location.protocol` 不能改成 https，沒辦法測 `wss:` 分支。
- **Fix:** deps 加上選填的 `location?: Pick<Location, 'protocol' | 'host'>`，預設 `globalThis.location`；介面其他欄位都照計畫原樣。

**4. [Rule 2] useLiveQuotes 對 FX / BOND 不套用 tick**
- **Found during:** Task 3
- **Issue:** 計畫只要求這兩類「永遠不是 ws」。如果照樣套用 tick，`degraded` 時這些列會顯示一個非 GET 的價格。
- **Fix:** 這兩類完全忽略 tick（後端本來就不會推它們的 tick，W4）。

**5. 節流實作為滑動視窗（見 key-decisions）**：保證比 token bucket 更嚴格，測試行為跟計畫的「第一秒只送 5 則、其餘延後」一致。

**6. `QuoteStream.ticks` 不用 Vue `readonly()` 包裝**：`ticks` 對外是 `shallowRef`，只用型別 `Readonly<Ref<…>>` 防止寫入；沒有用 Vue 的 `readonly()` 包住，因為那會把 Map 和每個 LiveTick 都包成深層 proxy，破壞 useLiveQuotes 依賴的物件身分比對。
