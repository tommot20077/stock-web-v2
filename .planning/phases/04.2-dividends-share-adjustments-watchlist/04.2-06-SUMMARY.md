## 函式簽章

```java
// HoldingCalculator（實例方法，與 applyBuy / applySell 同風格）
public Holding applyShareAdjustment(Holding existing, BigDecimal quantityDelta, OffsetDateTime now)

// ShareAdjustmentCalculator（final、private 建構子）
public static BigDecimal splitDelta(BigDecimal quantityAsOf, int ratioNew, int ratioOld)

// TradingDay
public Instant startOf(LocalDate tradingDate)
```

錯誤語意：
- `applyShareAdjustment`：existing 為 null 或持股 ≤ 0 → `TRADE_INSUFFICIENT_HOLDING`（fields `{symbol: "no holding"}`）；調整後持股 ≤ 0 → `TRADE_INSUFFICIENT_HOLDING`（無 fields）。
- `splitDelta`：quantityAsOf 為 null / ≤ 0、任一比例 ≤ 0、比例相等 → `IllegalArgumentException`（程式錯誤防線；service 層應先以 409 擋下）。
- `startOf(null)` → `NullPointerException("tradingDate must not be null")`。

### applyShareAdjustment

| 案例 | 輸入 | 期望 |
|---|---|---|
| D-05 配股 | 1000 @100，delta +50 | 1050 @ `95.23809524`；realizedPnl、id、userId、assetId、version 沿用；lastUpdated = now |
| 配股總成本 | 同上 | `|1050 × 95.23809524 − 100000| < 0.00001`（實際 100000.00000200，Pitfall 4） |
| 拆股 4:1 | 100 @400，delta +300 | 400 @ `100.00000000` |
| 合股 1:10 | 105 @10，delta −94.5 | 10.5 @ `100.00000000` |
| 合股 1:3 | 100 @30，delta −66.66666667 | 33.33333333 @ `90.00000001` |

| 持股為 0 | 0 股，delta +50 | `TRADE_INSUFFICIENT_HOLDING` |
| 結果為負 | 50 股，delta −300 | `TRADE_INSUFFICIENT_HOLDING` |
| 結果恰為 0 | 50 股，delta −50 | `TRADE_INSUFFICIENT_HOLDING` |

### TradingDay.startOf

| 市場 | 交易日 | 期望 instant |
|---|---|---|
| US | 2026-10-30（EDT） | `2026-10-30T04:00:00Z` |
| US | 2026-01-05（EST） | `2026-01-05T05:00:00Z` |
| TW | 2026-10-30 | `2026-10-29T16:00:00Z` |
| FX（17h） | 2026-10-30 | `2026-10-30T21:00:00Z` |
| FX（17h） | 2026-01-04 | `2026-01-04T22:00:00Z`（與既有 dayStart 案例相同） |
| CRYPTO | 2026-10-30 | `2026-10-30T00:00:00Z` |

一致性：US / TW / FX / CRYPTO × {2026-10-30, 2026-11-01（夏令結束日）, 2026-01-05, 2026-07-01}，`dayStart(startOf(d)) == startOf(d)` 且 `dayStart(startOf(d) + 1h) == startOf(d)`。
