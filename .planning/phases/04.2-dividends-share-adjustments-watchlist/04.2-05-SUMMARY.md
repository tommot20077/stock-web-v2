## Repository SQL（netByAsset）

```sql
select asset_id,
       sum(case when reversal_of_id is null then amount else -amount end) as net,
       sum(case when reversal_of_id is null then withholding_tax else -withholding_tax end) as tax
from cash_dividends
where user_id = :userId
group by asset_id
order by asset_id
```

本機以暫時的 PostgreSQL 16 叢集驗證（V16 DDL 原檔 + uuid / users / assets / prevent_append_only_mutation stub）：使用者 1 的 AAPL 120/30 + 10/0、沖銷 120/30 → `net 10, tax 0`；2330 500/50 沖銷後 → `0, 0`；使用者 2 的 999/9 只出現在使用者 2；查無使用者回 0 列；`EXPLAIN` 走 `idx_cash_dividends_user_asset`。驗證完已停機並刪除叢集目錄。
