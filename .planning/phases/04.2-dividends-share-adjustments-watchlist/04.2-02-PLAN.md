`POST /api/v1/portfolio/dividends`（`TRADE_EXECUTE`；Header `Idempotency-Key` 必填 1–128）
- `CreateDividendRequest { symbol @NotBlank @Size(max=32); amount @NotNull @DecimalMin("0.00000001") @DecimalMax("1000000000000") @Digits(integer=13,fraction=8); withholdingTax 選填 @DecimalMin("0") @DecimalMax("1000000000000") @Digits(integer=13,fraction=8)（省略 = 0）; paidAt OffsetDateTime 選填（省略 = 伺服器現在；> now + 5 分鐘 → 400 fields.paidAt）; note @Size(max=500); reversalOfId @Size(max=36) 選填 }`
- 標的須 active + tradeable（否則 404 `ASSET_NOT_FOUND`、`fields.symbol`）；無持倉 / 已賣光**可記**（D-03）
- 沖銷：帶 `reversalOfId`（原紀錄 uuid），`symbol` / `amount` / `withholdingTax` 必須與原列相同（不符 → 400 `fields`）、`paidAt` 省略 = 現在；原列不存在或非本人 → 404 `DIVIDEND_NOT_FOUND`；原列已被沖銷 → 409 `DIVIDEND_ALREADY_REVERSED`；原列本身是沖銷 → 409 `DIVIDEND_NOT_REVERSIBLE`
- 冪等：同 key 同 payload（assetId、amount compareTo、withholdingTax compareTo、paidAt（有送時截到微秒）、reversalOfId；**不含** note）→ 回既有列、不失效快取；不同 payload → 409 `DIVIDEND_IDEMPOTENCY_KEY_REUSED`
- `DividendDto { id(uuid), symbol, currency, amount, withholdingTax, paidAt, createdAt, note, reversalOfId, reversed }`；不回 idempotencyKey

`POST /api/v1/portfolio/share-adjustments`（`TRADE_EXECUTE`；Header `Idempotency-Key` 必填）
- `CreateShareAdjustmentRequest { symbol @NotBlank @Size(max=32); type @NotBlank（STOCK_DIVIDEND | SPLIT，白名單外 → 400 fields.type）; quantity（STOCK_DIVIDEND 必填）@DecimalMin("0.00000001") @DecimalMax("1000000000") @Digits(integer=10,fraction=8); ratioNew / ratioOld（SPLIT 必填）Integer @Min(1) @Max(1000)，兩者相等 → 400 fields.ratio; effectiveDate LocalDate 必填（yyyy-MM-dd，除權日）; note @Size(max=500); reversalOfId @Size(max=36) }`
- `effective_at = TradingDay.of(assetType, market).startOf(effectiveDate)`；`effective_at > now + 5 分鐘` → 400 `fields.effectiveDate`；`effective_at` 早於該標的最晚「未被沖銷且非沖銷列」調整的 `effective_at` → 400 `fields.effectiveDate`
- 事件日起點持股 `Q_asOf ≤ 0` 或目前持倉不存在 / ≤ 0 → 409 `TRADE_INSUFFICIENT_HOLDING`（D-06 / D-09）
- `quantityDelta`：STOCK_DIVIDEND = quantity；SPLIT = `Q_asOf × ratioNew / ratioOld`（scale 8、DOWN）− `Q_asOf`
- 沖銷：值（symbol / type / quantity 或 ratio / effectiveDate）必須與原列相同；只能沖銷該標的最晚一筆未沖銷調整、原列本身是沖銷 → 409 `SHARE_ADJUSTMENT_NOT_REVERSIBLE`；沖銷後持股 ≤ 0 → 409 `TRADE_INSUFFICIENT_HOLDING`；404 / ALREADY_REVERSED 同股利
- 冪等比對：assetId、type、quantity（配股）或 ratioNew + ratioOld（拆股）、effectiveDate、reversalOfId；**不含** note 與後端算出的 quantityDelta
- `ShareAdjustmentDto { id, symbol, currency, type, quantityDelta, ratioNew, ratioOld, effectiveDate, createdAt, note, reversalOfId, reversed }`

`GET /api/v1/portfolio/activities`（`PORTFOLIO_VIEW`）
- 參數與 `GET /trades` 同名同語意：`type`（BUY | SELL | DIVIDEND | SHARE_ADJUSTMENT；省略 = 全部；白名單外 → 400 fields.type）、`symbol`、`dateFrom`、`dateTo`（作用於 occurredAt，半開區間）、`sort`（executedAt | createdAt | total | quantity；executedAt = occurredAt）、`direction`、`page`、`size`
