<objective>
落實 D-01：symbol 選單、報價卡、走勢圖全部改接後端真實資料。

Purpose：這是 D-16「隱藏假資料」的**例外分支**首次正式套用 —— 判準是「能由後端真實推導就用真實資料，隱藏只適用於推導不出來的內容」。`AssetDto` 單一回應就同時帶 `symbol / name / sector / latestPrice / change / changePercent / volumeText / high / low`，報價卡的每一格後端都有，所以走「真實資料」分支（而 `cashAfter` 後端零命中，走「隱藏」分支 —— 同一張 ticket 上兩個分支並存是正確的）。

順帶解決一件事：symbol 必須是後端真存在且 `tradeable`，使用者不會送出去才吃 `ASSET_NOT_FOUND`。

Output：七態 typeahead（含 debounce + 競態處理 + 鍵盤操作）、真實報價卡、走勢圖三態。

|----------|-------------|
| 使用者按鍵 → `GET /api/v1/assets` | typeahead 每次按鍵都可能觸發請求；該端點是**公開端點**（`AssetController` 無 `@PreAuthorize`） |
| 亂序返回的多個回應 → 畫面 | 慢網路下舊查詢的結果覆蓋新查詢，是使用者可見的正確性錯誤 |
| 後端 JSON 型別 → 圖表數值 | `KlineDto` 的 OHLCV 是 string；當成 number 用不會有型別錯誤，只會有壓平／NaN 的圖 |
