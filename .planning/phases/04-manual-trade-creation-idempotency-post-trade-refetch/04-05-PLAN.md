<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 並行的多個 HTTP 請求 → 同一使用者的帳本 | 併發是重複寫入最難防的路徑，也是唯一約束存在的理由 |
| user A 的 key → user B 的交易 | 唯一約束的 user_id 維度是跨使用者隔離的唯一保證 |
| 例外 → HTTP 回應 body（完整字串，非只有 message） | key 可能從 message / fields / meta 任一處漏出 |
