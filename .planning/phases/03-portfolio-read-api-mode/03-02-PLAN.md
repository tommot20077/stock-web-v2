`portfolioApi.ts` 的介面（Plan 03/04/05 的消費契約）：

```typescript
export interface TradeListParams {
  symbol?: string;
  type?: 'BUY' | 'SELL';
  dateFrom?: string;      // ISO-8601 含 offset
  dateTo?: string;        // 半開區間 [dateFrom, dateTo)
  sort?: 'executedAt' | 'total' | 'quantity';
  direction?: 'asc' | 'desc';
  page?: number;          // 預設 0
  size?: number;          // 預設 20
}

export interface PortfolioLiveMockData {
  readonly trades: Trade[];       // src/types.ts 的 mock Trade 形狀，live store 資料
  readonly positions: Position[];
  readonly lastFill: { sym: string; type: 'BUY' | 'SELL'; qty: number; px: number } | null;
}

export interface PortfolioApi {
  mode: RuntimeDataMode;
  getSummary(): Promise<PortfolioSummaryDto>;
  listHoldings(): Promise<HoldingDto[]>;
  listTrades(params?: TradeListParams): Promise<PaginatedResponse<TradeDto>>;
  /** 僅 mock 實作提供；頁面在 mock mode 經此取得 reactive 資料（Q3 裁決） */
  live?: PortfolioLiveMockData;
}
```

http 端點對應（後端已存在，皆 `@PreAuthorize('PORTFOLIO_VIEW')`）：
- `getSummary` → GET `{basePath}/portfolio/summary` → `ApiResponse<PortfolioSummaryDto>` → `apiRequest`
- `listHoldings` → GET `{basePath}/portfolio/holdings` → `ApiResponse<List<HoldingDto>>`（純 List 不分頁）→ `apiRequest`
- `listTrades` → GET `{basePath}/trades` + query string → `ApiResponse<PageResponse<TradeDto>>` → `apiPaginatedRequest`

樣板：`backtestApi.ts`（createMock/createHttp/create 三件組 + `listRuns` 的 `apiPaginatedRequest` 用法）。
