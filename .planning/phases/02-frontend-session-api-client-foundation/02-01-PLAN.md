## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Vue app -> backend REST API | Browser code sends requests and receives untrusted JSON envelopes. |
| Domain adapters -> shared apiClient | Feature adapters must not bypass shared auth/security parsing. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `apiClient.ts` | mitigate | Do not add token fields or storage; default cookie transport uses `credentials: "include"` without exposing cookie values. |
| T-02-02 | Tampering | Domain adapters | mitigate | Remove duplicated direct paginated fetch helpers so later CSRF handling applies uniformly through `apiClient.ts`. |
| T-02-03 | Repudiation | Error handling | mitigate | Preserve backend `error.code`, HTTP status, and `meta.traceId`/request id in `ApiClientError`. |
| T-02-SC | Tampering | npm installs | accept | No package-manager install is planned; existing locked frontend dependencies are used. |
</threat_model>
