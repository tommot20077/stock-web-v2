## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Backend auth envelopes -> Vue session state | Untrusted response data becomes visible UI state. |
| Shared apiClient callbacks -> session model | Transport failures update global auth state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Information Disclosure | `authApi.ts` / `authSession.ts` | mitigate | Model only user metadata and expiry timestamps; tests reject access/refresh token persistence. |
| T-02-09 | Spoofing | session restore | mitigate | `/me` 401 clears stale user and enters anonymous state. |
| T-02-10 | Denial of Service | backend outage handling | mitigate | Session enters `error` with retry-ready metadata instead of repeated restore loops. |
| T-02-11 | Repudiation | session errors | mitigate | Preserve backend code/status/requestId in `SessionMessage` details. |
| T-02-SC | Tampering | npm installs | accept | No package-manager install is planned. |
</threat_model>
