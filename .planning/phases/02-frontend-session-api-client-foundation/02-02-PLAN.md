## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser cookies -> JS-readable CSRF cookie | Only the CSRF cookie is readable; auth cookies stay httpOnly and opaque to Vue. |
| `apiClient.ts` -> backend auth endpoints | Shared client triggers refresh and CSRF bootstrap using credentials. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | Tampering | unsafe requests | mitigate | `ensureCsrfToken` adds `X-XSRF-TOKEN` from `XSRF-TOKEN` before `POST`, `PUT`, `PATCH`, and `DELETE`. |
| T-02-05 | Denial of Service | refresh handling | mitigate | Single-flight refresh promise and per-request retry marker prevent refresh storms and infinite loops. |
| T-02-06 | Spoofing | stale auth state | mitigate | Refresh failure callback gives Plan 03 a deterministic path to mark the session anonymous/error. |
| T-02-07 | Information Disclosure | callback/error payloads | mitigate | Callback payload carries only code/status/message/requestId, never token or cookie values. |
| T-02-SC | Tampering | npm installs | accept | No package-manager install is planned. |
</threat_model>
